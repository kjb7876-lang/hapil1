# 합일 RC31 보스·모바일 최적화

GitHub Pages 정적 게임 배포본입니다. 게시 주소는 [https://kjb7876-lang.github.io/hapil1/](https://kjb7876-lang.github.io/hapil1/) 입니다.

## 모바일 변경

- 모바일 전투 화면은 뷰포트 전체를 덮습니다. 왼쪽 아래 이동 휠, 오른쪽 아래 **블링크(S)**와 **공명(D)**, 왼쪽 위 설정 버튼만 표시합니다. 세로 화면은 화면을 꽉 채우도록 고정 16:9 장면의 좌우를 잘라 표시합니다.
- 기본 공격과 일반 전투는 기존 반자동 동작을 유지합니다.
- 왼쪽 위 톱니바퀴에서 설정을 엽니다. 동료·성능 버튼은 전투 화면에 두지 않고 성능 선택은 설정 안에 둡니다.
- 전투판 위의 보스 체력·패턴 안내·위험 경고·상태 숫자는 숨깁니다. 보스 발밑에 그리는 체력 막대는 그대로 보입니다.
- 모바일은 저사양 효과, 점멸 감소, 화면 흔들림 끄기로 시작합니다. 렌더 축척은 절전 0.32, 균형 0.40, 고화질 0.52로 제한하고 HUD 상태 갱신은 450ms 간격으로 늦춰 픽셀·DOM 작업을 줄입니다. 전투 판정과 피해량은 유지합니다.
- 저장된 성능 모드는 유지하되 새 기기는 절전 렌더로 시작합니다. 화질 선택은 설정에서 바꿀 수 있습니다.

## 배포 파일

`index.html`, `assets/`, `audio/`, `data/`, `.nojekyll`은 모두 저장소 최상단에 둡니다. ZIP 파일 자체를 저장소에 올리지 마세요. 게임 자료는 공개 저장소의 일부이므로 누구나 내려받을 수 있습니다.

## RC30 보스 연출 수정

- 72개 보스·중간 보스 레이저 등록을 점검하고, 루시퍼 공용 레이저로 잘못 연결된 70개를 각 보스 전용 `v31330/<보스 ID>/beam.webp` 이미지로 연결했습니다. 루트 수문장과 네이티브 루시퍼 레이저는 각자 기존 전용 이미지를 유지합니다.
- 보스 그림을 재사용하는 잔영 분신은 소환 원본 보스의 현재 렌더 높이에 맞춰 그립니다. 일반 몹 그림 분신은 기존 크기를 유지하고, 체력 표시 폭도 보스 그림 크기에 맞춥니다.
- 보스 분신의 크기 조정은 그리기만 바꾸며 전투 판정과 크기는 그대로 둡니다.
- 레이저 이미지 전수 검사와 분신 크기 회귀 검사는 `node tests/boss-visual-smoke.cjs`로 실행할 수 있습니다. [RC30 검증 기록](RC30_VERIFICATION_KO.md)


## RC31 보스·모바일 최적화

- 발록, 루시퍼, 7죄악 호텔 보스, 에피소드 결전 보스, 우주·수문장 보스 등 중요 보스 28종에 각각 다른 레이저 모티프 SVG를 연결했습니다. 다른 보스도 기존 보스별 색상 텍스처를 유지합니다. 기존 얇은 밝은 중앙 보조선은 렌더 중 제거하고 주 레이저 이미지만 남깁니다.
- 모든 보스는 고유 색의 블랙홀을 소환합니다. 1.25초 예고 뒤 반경 안의 영웅을 중심으로 끌어당기며, 공명(D)을 유지하면 끌림을 막습니다.
- RC31 동작 회귀 검사는 `node tests/rc31-upgrade-smoke.cjs`, RC30의 72개 레이저/분신 검사는 `node tests/boss-visual-smoke.cjs`입니다.
- [RC31 검증 기록](RC31_VERIFICATION_KO.md)
