# 합일 RC30 보스 연출 수정

GitHub Pages 정적 게임 배포본입니다. 게시 주소는 [https://kjb7876-lang.github.io/hapil1/](https://kjb7876-lang.github.io/hapil1/) 입니다.

## 모바일 변경

- 전투판이 화면 전체 영역을 사용합니다. 왼쪽 아래 터치 휠로 이동하고, 오른쪽 아래에는 **블링크(S)**와 **공명(D)** 두 버튼만 겹쳐 놓습니다.
- 기본 공격과 일반 전투는 기존 반자동 동작을 유지합니다.
- 왼쪽 위 톱니바퀴 하나에서 설정을 엽니다. 별도 동료·성능 버튼은 전투 화면에 표시하지 않습니다. 모바일 성능의 `절전 / 균형 / 원본` 선택은 설정 안에 있습니다.
- 체력·공명과 보스 체력·위험 경고는 전투판 위에 작게 표시하되, 상세 상태 패널은 모바일에서 갱신하지 않습니다.
- 새 모바일 기기는 절전 렌더 축척 상한 0.55, 저사양 효과, 점멸 감소, 화면 흔들림 끄기로 시작합니다. 이미 저장한 그래픽 선택은 보존합니다. 전투 판정·피해량·타이밍은 변경하지 않았습니다.
- 세계와 카메라의 16:9 비율을 유지하여 위험 지역을 자르지 않습니다. 가로 화면에서 전투판이 가장 크게 보입니다. 세로 화면에서는 전체 맵을 보존하려고 남는 공간이 있을 수 있습니다.

## 배포 파일

`index.html`, `assets/`, `audio/`, `data/`, `.nojekyll`은 모두 저장소 최상단에 둡니다. ZIP 파일 자체를 저장소에 올리지 마세요. 게임 자료는 공개 저장소의 일부이므로 누구나 내려받을 수 있습니다.

## 검증 범위

RC28 검사에서 활성 JavaScript 41개 문법, HTML 로컬 파일 참조 54개, DOM 모의 실행의 초기화·8방향 이동·멀티터치 공명 취소·설정 진입을 확인했습니다. 실제 iPhone Safari·Android 실기 FPS는 측정하지 못했으므로 기기별 체감 검증이 필요합니다. `RC26_VERIFICATION_KO.md`는 이전 RC26 검증 기록입니다.

## RC30 보스 연출 수정

- 72개 보스·중간 보스 레이저 등록을 점검하고, 루시퍼 공용 레이저로 잘못 연결된 70개를 각 보스 전용 `v31330/<보스 ID>/beam.webp` 이미지로 연결했습니다. 루트 수문장과 네이티브 루시퍼 레이저는 각자 기존 전용 이미지를 유지합니다.
- 보스 그림을 재사용하는 잔영 분신은 소환 원본 보스의 현재 렌더 높이에 맞춰 그립니다. 일반 몹 그림 분신은 기존 크기를 유지하고, 체력 표시 폭도 보스 그림 크기에 맞춥니다.
- 보스 분신의 크기 조정은 그리기만 바꾸며 전투 판정과 크기는 그대로 둡니다.
- 레이저 이미지 전수 검사와 분신 크기 회귀 검사는 `node tests/boss-visual-smoke.cjs`로 실행할 수 있습니다. [RC30 검증 기록](RC30_VERIFICATION_KO.md)
