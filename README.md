# 합일 게임

## RC44 보스 공격 리듬과 탄막 연출

기존 맵, 카메라와 저장 형식(14)을 유지하면서 실제 보스 공격 예약에 부채꼴·안전 틈이 있는 원형·통로형 탄막을 연결했습니다. 네 보스의 비석 낙하·전장 소거포 특수 공격도 해당 순서에 들어갑니다. 한 공격에서 피해는 기존 투사체 또는 피격 예약이 한 번만 처리합니다.

탄막은 발사 지점의 예고 뒤 2~3묶음으로 나뉘어 날아가고, 마지막 묶음이 목표 지점에 도달한 뒤 약 0.85초의 반격 시간을 둡니다. 발사음은 묶음당 한 번 재생하며, 기존 투사체 그림 경로에 짧은 비행 잔상을 더했습니다. RC43 혈흔 무기 그림은 그대로 선택되고, 저사양 설정에서는 잔상과 추가 예고 고리를 생략합니다. 레이저가 진행 중이거나 탄환이 많을 때는 추가 특수 탄막 대신 기존 안전장치를 따릅니다.

`node tests/rc44-boss-choreography-smoke.cjs`는 실제 게임 번들에서 공격 예약과 렌더 코드를 추출해 안전 통로, 발사 시점, 피해 예약, 무기 이미지, 저사양 경로, 기존 공격 대체 경로를 확인합니다. 실기 화면의 회피 난도와 프레임은 별도로 플레이 확인이 필요합니다.

## RC43 새 탄환 비행 수정

RC39·RC41의 도끼·식칼·지폐·보물·휴지·주사기·자동차·트럭 자산을 해당 적의 **이동하는 탄환**에 연결했습니다. 시전 중 제자리에서 잠깐 보이던 탄환 이미지 배치는 제거하고, 보스의 예고가 끝나면 발사 위치에서 목표 지점까지 약 1.1~2.3초 동안 한 발의 이미지가 날아갑니다. 기존 피격 예약이 도착 시점에 판정하므로 추가 피해를 중복 생성하지 않습니다. 일반 적의 원거리 탄환도 해당 이미지로 그리되 적 캐릭터의 모습은 유지합니다. `node tests/rc43-bloodied-projectile-flight.cjs`로 경로, 비행 시간, 위치 변화와 피해 예약 보존을 확인할 수 있습니다.

GitHub Pages 정적 게임 배포본입니다. 게시 주소는 [https://kjb7876-lang.github.io/hapil1/](https://kjb7876-lang.github.io/hapil1/) 입니다.

## 모바일 변경

- 모바일 전투 화면은 뷰포트 전체를 덮습니다. 왼쪽 아래 이동 휠, 오른쪽 아래 **블링크(S)**와 **공명(D)**, 왼쪽 위 설정 버튼만 표시합니다. 세로 화면은 화면을 꽉 채우도록 고정 16:9 장면의 좌우를 잘라 표시합니다.
- 기본 공격과 일반 전투는 기존 반자동 동작을 유지합니다.
- 왼쪽 위 톱니바퀴에서 설정을 엽니다. 동료·성능 버튼은 전투 화면에 두지 않고 성능 선택은 설정 안에 둡니다.
- 전투판 위의 보스 체력·패턴 안내·위험 경고·상태 숫자는 숨깁니다. 보스 발밑에 그리는 체력 막대는 그대로 보입니다.
- 모바일은 저사양 효과, 점멸 감소, 화면 흔들림 끄기로 시작합니다. RC102에서 렌더 축척은 모바일 세로 확대율과 기존 부하 상태를 반영합니다. 절전 0.32, 균형 최대 0.80, 고화질 최대 1.25로 제한하며 기기 DPR 전체를 강제하지 않습니다. HUD 상태 갱신은 450ms 간격으로 늦춰 픽셀·DOM 작업을 줄입니다. 전투 판정과 피해량은 유지합니다.
- 저장된 성능 모드는 유지하되 새 기기는 균형 렌더로 시작합니다. 화질 선택은 설정에서 바꿀 수 있습니다.

## RC30 보스 연출 수정

- 72개 보스·중간 보스 레이저 등록을 점검하고, 루시퍼 공용 레이저로 잘못 연결된 70개를 각 보스 전용 `v31330/<보스 ID>/beam.webp` 이미지로 연결했습니다. 루트 수문장과 네이티브 루시퍼 레이저는 각자 기존 전용 이미지를 유지합니다.
- 보스 그림을 재사용하는 잔영 분신은 소환 원본 보스의 현재 렌더 높이에 맞춰 그립니다. 일반 몹 그림 분신은 기존 크기를 유지하고, 체력 표시 폭도 보스 그림 크기에 맞춥니다.
- 보스 분신의 크기 조정은 그리기만 바꾸며 전투 판정과 크기는 그대로 둡니다.
- 레이저 이미지 전수 검사와 분신 크기 회귀 검사는 `node tests/boss-visual-smoke.cjs`로 실행할 수 있습니다. [RC30 검증 기록](RC30_VERIFICATION_KO.md)


## RC31 보스·모바일 최적화

- 발록, 루시퍼, 7죄악 호텔 보스, 에피소드 결전 보스, 우주·수문장 보스 등 중요 보스 28종에 각각 다른 레이저 이미지를 연결합니다. 기존 SVG 원화는 이미지 로더가 지원하는 WebP로 변환해 전투 중 실제 텍스처로 표시합니다. 기존 얇은 밝은 중앙 보조선은 렌더 중 제거합니다.
- 모든 보스는 고유 색의 블랙홀을 소환합니다. 1.25초 예고 뒤 반경 안의 영웅을 중심으로 끌어당기며, 공명(D)을 유지하면 끌림을 막습니다.
- RC31 동작 회귀 검사는 `node tests/rc31-upgrade-smoke.cjs`, RC30의 72개 레이저/분신 검사는 `node tests/boss-visual-smoke.cjs`입니다.
- [RC31 검증 기록](RC31_VERIFICATION_KO.md)


## RC32 텍스트·스킬 이미지 표시 수정

- 첫 서사 문구의 `그들을 ID(이드)`를 `그들은 ID(이드)`로 바로잡고, 이미 로드된 서사 데이터와 DOM·Canvas 출력에도 같은 보정을 적용합니다.
- 이미지 로더가 PNG/JPEG/WebP만 허용해 SVG 레이저가 빠지고 선 대체 효과만 보이던 원인을 수정했습니다. 28종의 보스별 레이저를 지원되는 WebP로 연결하고, ImageGen으로 만든 투명 블랙홀 원화 4종(용암·천상·죄악·심연)을 계열별 보스에 적용합니다. 원화는 512px WebP로 최적화해 모바일 전송량을 줄였습니다.
- `node tests/rc31-upgrade-smoke.cjs`와 `node tests/rc32-image-text-smoke.cjs`로 텍스처 연결, 실제 캔버스 이미지 그리기, 문구 보정을 검사합니다. [RC32 검증 기록](RC32_VERIFICATION_KO.md)

## RC108 누적 UI·전투 수정

PC와 가로 모바일은 상단 정보 10%, 전장 90%를 사용합니다. 세로 모바일은 전장 전체와 보스/영웅 듀얼뷰를 사용하며 이동·블링크·공명·설정을 유지합니다. 수동 모바일에서는 사격/차지와 추가 조작을 표시합니다.

레이저의 공용 렌더/접촉 형상을 연결하고 안전 통로를 보존했습니다. 피해 배율, 사몽 ×7, EGO 진입 쿨다운, 7회 벽 반사 및 최종 서사 순서를 누적 적용했습니다. 검사 범위와 한계는 [RC108 검증 기록](RC108_VERIFICATION_KO.md)을 참조하세요.
