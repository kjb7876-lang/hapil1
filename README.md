## 모바일 변경

- 왼쪽 아래 가상 스틱으로 이동합니다.
- 오른쪽 아래 전투 버튼은 **블링크(S)**와 **공명(D)** 두 개만 둡니다.
- 기본 공격과 일반 전투는 기존 반자동 동작을 유지합니다.
