# RC99 전투 정보 배치

전체 전투 프레임의 가로 폭을 적 정보 10%, 전투 화면 80%, 아군 정보 10%로 나눈다. 중앙 전투 캔버스는 16:9를 유지하며 하단에 영웅, 공명 수치·EGO·차징, 조작 버튼, Q/W/E/R 상태를 둔다. 전투 화면을 가리던 대상·보스 정보·파티 창의 중복을 제거하고 기존 적·아군 패널을 사용한다. 전장의 영웅·적·탄막·공격 예고는 기존 렌더러가 그대로 그린다.

화면 높이에 맞춰 전체 프레임이 축소되므로 가로가 긴 모바일에서도 비율을 보존한다. 모바일 세로 화면은 중앙이 작고 좌우 정보가 좁다. 좁은 정보 패널은 스크롤하며 전투는 가로 화면을 권장한다. 모바일 이동 휠·블링크·공명 입력은 기존 핸들러를 유지하고 하단으로 배치했다. 전체화면과 설정은 모바일 상단에 둔다. 안전 영역의 위·아래 여백을 반영한다.

스킬 상태는 실제 `state.cooldowns[skill.key]`에서 읽고 궁극기에 필요한 공명 조건을 함께 표시한다. 스킬 시전, 자동 공격, 밸런스, 저장을 변경하지 않는다. 모달·서사가 열리면 스킬 상태를 숨긴다.

Linux Chromium에서 PC 1280×900·1920×1080, 터치 가로 844×390·세로 390×844의 비율, 패널 위치, 캔버스 클릭 영역, 하단 버튼 위치, Q 재사용 시간, 설정 메뉴 열기를 검사했다. 캡처는 실제 UI와 게임 렌더러에 재현용 보스 전투 상태를 연결한 장면이다. 실제 iPhone/Safari 전체 캠페인 검증은 아니다.
