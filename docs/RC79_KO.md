# RC79 전투 및 이미지 수정

기준 파일 트리: RC78 3919368d209a2c044b3d87399b94a85fc9dc4492

- 레이저: 색상 하나의 연속된 굵은 띠. 텍스처 조각, 백색 중심, 교차점 광원 제거. 기본 패턴의 굵기와 충돌 반경 25% 확대. 궁극기 레이저 반경 18→23px. 레이저 이미지 로딩과 무관하게 단색 렌더러의 판정을 활성화.
- 블링크: 방향키 우선. 입력을 놓으면 최근 수동 이동 방향 사용. 지형 경계에서 입력 방향 직선상에만 착지하며 주변 빈 지점으로 옆 이동하지 않음. 완전자동 회피 호출은 기존 완전자동 모드에서만 허용.
- 한리안/백이온: RC55 정지 그림과 이전 공격 그림 혼합 제거. 기존 방향/행동 이미지 40개 연결 및 우선 로딩. 512px 전체 캔버스와 공통 발 위치로 출력하여 갑옷과 무기를 크롭하지 않음.
- 레이저를 제외한 일반 스킬: 바닥 예고를 감추고 짧은 시전 후 실제 이미지 공격 실행. 반복 공격 간격 유지. 낙하 궁극기의 바닥 원형 예고 제거, 낙하물 이동 자체는 표시. 일반 스킬 이미지는 바닥 도형으로 자르지 않고 전체 비율로 출력.
- 보스 연속 폭딜 상한: 보스 초당 최대 체력 8%, 중간보스 14%, 사몽 최종전 1.4%의 회복형 피해 예산. 일반적인 작은 피해는 그대로이며 비정상적인 큰 피해가 순간 처치를 만들지 않도록 제한.
- 사몽 최종전: 교주 체력은 각성 전 최대 체력의 95%로 재설정. 대사/일시정지/숨겨진 탭을 제외한 활성 플레이 시간 60초 이전에는 최종 타격 불가. 적 슬로모션의 시계와 분리. 실제 전투 경과 시간을 저장/복원하고 이전 버전의 중간 저장은 최종전 체력을 복원하여 재개.
- 교주가 실제로 처치되어 최종전이 완료될 때만 마지막 독백과 엔딩을 진행.

## 확인

Node 문법 검사와 RC79 동작 검사, RC68/72/74/75/76/77/78 회귀 검사 및 boss-visual-smoke 통과.
RC79 검사는 실제 게이트 함수를 호출하여 수동/완전자동 60초 이전 처치 차단을 확인하고, 무제한 피해 입력을 60Hz로 가한 정책 단독 시험에서 약 70.4초가 걸리는 것을 확인함. 실제 전투 시간은 다른 피해 제한과 공격 빈도에 따라 더 길어질 수 있음.
선택한 40개 이미지의 파일 존재 및 알파 경계가 캔버스 안에 있는 것을 확인.
브라우저 실행 파일 다운로드가 실패하여 실제 브라우저 플레이/시각 회귀 검증은 수행하지 못함. 모든 상황에 버그가 없다고 보증하지 않음.
