# RC80 추가 회귀 수정

RC79의 굵은 단색 레이저, 방향 입력 블링크, 배신자 기존 40개 포즈 복원, 비레이저 바닥 예고 제거 및 최종전 최소 60초 보호를 포함한다.

- 스킬 적중 이미지를 구형 뿌리/무기 렌더러보다 먼저 처리하여 수정된 출력 경로가 우회되지 않게 했다.
- 최종전 활성 시간은 최종 일시정지 판정 후 실제 프레임 시간으로 누적한다. 긴 프레임은 0.25초까지만 인정한다.
- 이전 저장의 누락된 전투 시간을 구분해 최종전 체력을 복구하고, 새 저장은 진행 시간과 체력을 유지한다.
- 보스 피해 예산은 실제 피해 적용 함수에 배치해 진단용 체력 조회가 예산을 소비하지 않도록 했다.
- 블링크 마지막 수동 방향은 같은 영웅과 같은 맵에서만 재사용한다.

검증: RC68/72/74/75/76/77/78/79/80 및 boss-visual-smoke 총 10개 Node 검사 통과. JavaScript 문법 및 git diff 공백 검사 통과. 포화 피해 시뮬레이션에서 최종전은 약 70.4초 지속했다. 실제 브라우저/Windows 실행은 이 환경에서 검증하지 못했으며 실제 플레이 무결성을 보장하지 않는다.
