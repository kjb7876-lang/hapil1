# RC82 · 영웅 선택 후 접속 준비에서 멈추는 문제

RC81 배포 후 영웅 선택에서 접속하면 준비 상태가 끝나지 않는 문제를 실제 배포 페이지에서 재현했다. 브라우저 콘솔에는 `HAPIL 3.13.32 laser module installation failed`가 나온 뒤 전투·시작 대사·맵 경로·영웅 이미지 준비 타임아웃이 기록됐다.

RC79~RC81에서 메인 게임 번들이 바뀌었지만 `index.html`의 주소는 계속 `index-v31526.js?v=38101`이었다. 브라우저/CDN이 이전 번들을 재사용할 수 있으므로, 메인 번들과 함께 RC79 정책, 영웅 컨트롤, 서사, 레이저 렌더러의 캐시키를 갱신했다. 게임 로직은 건드리지 않고 실제 변경된 파일을 새 URL로 요청하도록 했다.

확인: `node tests/rc82-launch-cache-smoke.cjs`는 캐시키와 의존 스크립트 순서를 검사한다. 기존 RC45, RC46, RC76, RC77, RC78 전투 회귀 스모크도 모두 통과했다. 재배포 뒤에는 새 URL로 받은 모듈의 준비 상태를 브라우저에서 다시 확인한다.
