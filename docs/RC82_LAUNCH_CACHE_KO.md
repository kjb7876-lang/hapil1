# RC82 · 영웅 선택 후 접속 준비에서 멈추는 문제

RC81 배포 후 영웅 선택에서 접속하면 준비 상태가 끝나지 않는 문제를 실제 배포 페이지에서 재현했다. 브라우저 콘솔에는 `HAPIL 3.13.32 laser module installation failed`가 나온 뒤 전투·시작 대사·맵 경로·영웅 이미지 준비 타임아웃이 기록됐다.

RC79~RC81에서 메인 게임 번들이 바뀌었지만 `index.html`의 주소는 계속 `index-v31526.js?v=38101`이었다. RC82에서 캐시키를 갱신했지만, 배포 페이지가 새 번들 `v=38102`를 실행한 뒤에도 같은 초기화 타임아웃이 재현됐다. 캐시 주소는 갱신됐으나 원인은 캐시가 아니었다.

RC83은 준비 타임아웃에 앞선 `3.13.00~3.13.18` 릴리스 게이트와 주요 초기화 모듈 상태를 콘솔의 `[HAPIL_BOOT_DIAG_RC83]` 기록으로 남긴다. 이 상태를 확인해 처음 막힌 의존성을 바로잡는다. 진단 스크립트는 전투 데이터나 저장 파일을 변경하지 않는다.
