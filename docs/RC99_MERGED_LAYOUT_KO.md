## 보존한 내용
RC95 전투 흐름·밸런스, RC96 차징 중 자동공격, RC97 선택형 패턴, RC98 레이저 끝부분 등 누적 전투 변경을 포함합니다.
UI 관련 파일을 제외한 RC99 원본의 변경 자산 13개는 병합 후 SHA-256이 원본과 동일합니다. 게임 번들, 조작/전투 로직, 레이저 파일을 이번 UI 병합 과정에서 다시 바꾸지 않았습니다.
RC96 공명/EGO/차징 표시의 계산 함수도 그대로 유지하고 표시 위치만 조정했습니다.

## 최신 UI
- PC: 적 10% / 전투 80% / 아군 10% 영역을 분리. 실제 전투 캔버스는 기존 16:9 비율과 기존 포인터 좌표 변환 유지
- 상단 설정과 하단 영웅·공명·수동 조작 영역은 전투 영역 밖에 배치
- 긴 공격 예고와 동료 상태는 각 정보 패널 내부에서 줄바꿈·스크롤
- 반자동/자동 모드에서는 자동 스킬 버튼을 숨김. 수동 모드에서는 해당 버튼을 유지하되 스킬 단축키 표시는 생략
- 별도 자동 스킬 키/쿨다운 패널 제거
- PC 공명/EGO/차징은 전용 하단 열에 표시. 필수 상태/오류 알림도 하단에 예약된 22px 줄로 이동
- 모바일: 화면을 채우는 전투 중심. 작은 영웅 체력·공명/EGO 상태, 작은 보스 체력, 설정, 이동 휠, 블링크, 공명만 기본 표시
- 모바일에 PC의 10:80:10 정보를 억지로 배치하지 않음
- 상세 적·아군 정보는 설정의 ‘전투 상세 정보 · 적 / 아군’에서 확인
- 판정에 필요한 게임 내 공격 예고와 기존 캐릭터/보스 렌더링 유지

수정된 최종 화면의 실제 렌더링, 실제 기기 터치, FPS, 스크린샷은 확인하지 못했습니다.
Chromium 실행이 환경의 소켓 권한 오류로 실패했고, 제공 브라우저도 로컬 미리보기 주소를 차단했습니다. 제한을 우회하지 않았습니다.

Playwright와 Chromium이 있는 환경에서 실행할 최종 반응형 검사:

## 적용 방법
이 파일은 전체 게임이 아니라 공개 RC94 저장소에 적용하는 누적 수정 패키지입니다. 기존 이미지·음원을 그대로 사용합니다.
1. 먼저 작업 중인 변경을 백업하고 현재 커밋을 확인하세요.
2. 기준 커밋이 위의 RC94와 같으면 저장소 루트에서:

       git apply --check /path/to/hapil-rc99-merged.patch
       git apply /path/to/hapil-rc99-merged.patch

3. changed-files 폴더에 변경 파일 전체도 같은 상대 경로로 포함되어 있습니다. 패치와 파일 복사는 둘 중 하나만 사용하세요.
4. 이미 다른 RC95–RC99 작업본이나 추가 수정이 있으면 전체 파일을 덮어쓰지 말고 기준 차이를 확인해 병합해야 합니다.
5. 반응형 브라우저 검사를 마친 뒤 게시 여부를 결정하세요. 이 패키지에 자동 push/배포 실행 파일은 없습니다.
