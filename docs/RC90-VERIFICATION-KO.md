# RC90 누적 검증과 업로드

기준 GitHub: kjb7876-lang/hapil1 main, e1bb67a90a7fa052424c3175df3daa536c69b2fe (RC85). RC86~RC90의 미게시 변경 전체를 포함한다. 구버전 스크립트를 순서대로 실행하지 않고 이번 스크립트 하나만 실행한다. 실제 업로드는 사용자의 PowerShell 실행 시 수행된다.

## 추가 검증으로 발견·수정한 오류

1. 아르벨리아 전투를 저장하고 불러오면 명령 핵은 복원되지만 본체 보호 상태가 누락됐다. 명령 핵 생성 기록 때문에 재설정 경로도 건너뛰었다. 복원 직후 보호 상태를 적용하고, 생성 기록이 이미 있어도 본체를 보호하도록 수정했다.
2. 실제 로더는 진입 상태를 먼저, 최종전의 시간을 나중에 복원한다. 사몽 소환 종료·다음 호출·약점 시간을 앞 단계의 세계 시간으로 계산해 현재 망령이 즉시 만료될 수 있었다. 망령 최대 체력도 저장하고 기존 저장 파일에는 저장된 교주의 최대 체력으로 보정한다. 정규화된 저장 파일의 최종전 시간을 사용해 복원하고, 실제 순서대로 복원한 후 첫 틱까지 현재 망령이 남는지 검증했다.

## 누적 내용

- 기사형 배신의 목사 2인의 대기·공격 자산과 활성 이미지 경로 일관화.
- 중요 에피소드 보스 이후 코스믹 여섯 진최종전 및 후속전 저장 복원.
- 최후 교주의 사몽: 코스믹 여섯 망령의 고유 탄막, 반투명 흑백 몸체, 교주 연결선, 격파 시 방벽 약화. 원래 인물과 교주의 망령 소환을 구분하는 독백 보충.
- 뿌리 핵·명령 장치·모방체·검격 모조체를 기존 피격·탄막 기능으로 격파. 부속의 다음 발사를 멈추고 이미 발사된 탄막은 기존 수명까지 유지.
- 아르벨리아 명령 핵 세 개 격파에 따른 비살상 해방, 생체 부트로더 전투 후 연결 연출과 독백 순서, 라우렌 창 자산으로 두 주인의 지원, 한이경의 기억 화자 표시.
- 사몽 체력·소환 순서·방벽 격파·체류 시간·약점 시간 및 부트로더 연결 잔여 시간 저장. 반복 강화탄 중앙 문구 제거.

## 검증 범위

비브라우저 테스트 47개와 추적 JavaScript/CJS 207개 구문 검사를 통과했다. 브라우저 RC85·86·87·88·90을 확인했다. RC90은 PC 1280×900과 모바일 414×896에서 실제 영웅 피해 콜백으로 명령 핵을 격파하고, 보상·해방·독백 및 부트로더→코스믹→전투 후 독백을 확인한다. 사몽 복원은 실제 함수 호출 순서를 사용해 현재 망령의 HP와 잔여 체류 시간을 확인한다.

첫 전투의 자연 처치 검증에는 플레이어 생존 보조를 사용했다. 후반 진행 검사에는 보스 HP/시간을 준비한 상태를 사용한다. 전 에피소드 자연 플레이 난이도, 실제 휴대전화 성능, Windows의 GitHub 인증 및 업로드는 여기서 검증하지 않았다. PowerShell 실행 시 모든 구문 검사와 47개 비브라우저 테스트를 다시 통과한 뒤 업로드하며 브라우저 테스트는 건너뛴다.

업로더는 새로운 작업 폴더를 만들고 LF를 사용한다. 내장 패치 SHA-256과 결과 Git tree를 검사하고, 테스트 실패 또는 변경된 원격 기준에서는 중단한다. 강제 push와 기존 작업 폴더 덮어쓰기는 사용하지 않는다. 게시 후 게임 주소의 버전 값은 39001이다.
