# RC85 · 첫 전투 블링크 오류와 전투 시각 일관성

기준: RC84 `e0447e927b386cbdc3dc00fb7ed43936d81320cd`.

## 재현한 오류

실제 브라우저에서 첫 전투 중 S를 누르면 `TypeError: ut is not a function`이 발생했다. React 컴포넌트 안의 `ut` 능력치 객체가 모듈 전역의 지형 충돌 검사 함수 `ut`를 가렸다. RC79 블링크 경로가 이 객체를 함수처럼 호출한 것이 원인이다. 자동 회피도 같은 dash 콜백을 사용하며, 프레임 안에서 예외가 나면 다음 프레임 예약에 도달하지 못할 수 있었다.

전역 범위의 `HAPIL_blinkWalkableRC85`가 현재 지형 검사 함수를 호출하도록 변경했다. 지형 판정·블링크 거리·피해 밸런스는 유지했다. 수동 S 재현 및 자동회피 플래그를 사용하는 실제 dash 콜백을 검사했다.

첫 전투 중 멈춤 신고의 모든 경우가 같은 원인이라고 단정하지 않는다. 사망 안내창과 전투 전후 서사창은 의도적으로 시간을 정지하며, 닫으면 재개되는 것도 확인했다.

## 레이저

일반·혈광·궁극기 세 렌더링 경로에서 보스별 빔 이미지를 공통 렌더러에 전달한다. RC79의 굵은 단색 막대 대신 이미지의 중심 구간을 실제 충돌 선분에 맞춰 그린다. 큰 발사구/폭발 그림이 분기점마다 반복되지 않는다. 보스별 화염·성광·우주·죄악 이미지의 질감을 유지한다. 저사양 모드는 옅은 외곽 이미지 레이어를 생략하며, 이미지 미로딩 시에는 가느다란 중심광과 반투명 외곽으로 대체한다. 이동 패턴과 충돌 판정은 변경하지 않았다.

## 악몽검사

대기·이동·일반 공격·스킬·방어·대시·피격을 같은 RC5 방향별 원본 세트로 통일했다. RC49 정면 전용 그림과 RC81 측면 전용 그림이 특정 동작에서 몸 전체를 교체하던 경로를 해제했다. 기존 파일은 보존한다. 방향별 발 위치와 신체 배율을 유지하고, 공격 중 방향 고정을 보존한다. 스프라이트 방향과 무관하게 대각선 투사체를 정면 발끝에서 생성하던 보정도 제거했다. 정면 출발점은 통일된 상체 자세에 맞춰 조정했다.

서로 다른 그림체의 추가 프레임보다 신체·갑옷·검의 연속성을 우선한 변경이다. 새 그림을 생성했다고 주장하지 않는다.

## 검증

- Node 회귀 검사 42개 통과. 변경된 표현 규칙에 해당하는 기존 검사를 갱신하고 원래의 피해·상태·자산 검사는 유지했다.
- `rc61-launch-settings-browser.cjs`: 8명 PC, 악몽검사 모바일 390×844, 이동·블링크·첫 전투·설정 검사, 페이지 오류 0건. 의존성 부족 시 재시도 검사 통과.
- `rc85-combat-browser.cjs`: 자동회피 플래그의 실제 dash 콜백, 전투 시간 재개, 첫 보스의 실제 공격 피해로 처치, 전투 후 서사창과 재개, 보스 레이저 이미지 출력, 악몽검사 28개 방향/행동 조합 검사.
- 첫 보스 진행 회귀 검사는 처치 경로를 분리해서 확인하기 위해 플레이어 체력을 보충한다. 적 체력과 공격 피해는 변경하지 않는다. 일반 플레이 난도/무사망 클리어를 보장하는 시험은 아니다.
- 실제 렌더링으로 방향별 자세와 보스 레이저 연결부를 시각 확인했다.

사용 브라우저: Chrome Headless Shell 131 (Linux), Playwright. 실제 휴대전화 GPU/터치 지연과 전체 캠페인 완주는 이번 검사 범위에 포함하지 않는다.
