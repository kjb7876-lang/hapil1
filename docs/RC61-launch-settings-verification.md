# RC61 시작 검은 화면·서문·설정 수정

## 확인한 원인

브라우저에서 악몽검사를 선택하고 접속하면 게임 상태로 전환되지만 전투 모듈이 준비되지 않아 프레임이 대기하고, `HAPIL 3.13.32 laser module installation failed` 오류가 발생했다.

1. RC55 추가 이미지로 선행 로딩 목록이 20개를 초과했다. 기존 promote 함수는 새 항목일 때 한 개만 내리므로 이미 넘친 목록을 복구하지 못했다. `preloadTierBounded` 검사 실패가 뒤쪽 전투 모듈의 초기화를 막았다.
2. RC60이 초기 월드의 포털 연결에서 빈 기록을 먼저 제외했지만, 이전 초기화 검사는 전체 카탈로그와 포털 경로 길이의 일치를 요구했다. 경로 변경을 초기화 이후에 적용하도록 이동하고, 전투 흐름의 다음 맵 참조도 함께 수정했다.
3. 접속 버튼은 위 준비 상태를 확인하지 않고 게임으로 전환했다. 새 게임은 빈 허브에서 시작하여 첫 독백도 바로 표시되지 않았다.

## 수정

- 선행 로딩 목록이 이미 넘친 경우에도 20개까지 정리한다. 자산은 삭제하지 않고 다음 로딩 단계에 보존하며 선택 자산과 보호 자산은 유지한다.
- 초기화 완료 후 삭제 기록 경로·세이브 호환을 설치한다. 실제 경로는 발록전 후 병원으로 이어진다.
- 새 게임 접속은 전투·대사·맵 경로·영웅 이미지·맵 로더의 준비를 확인한다. 12초 이내 준비되지 않으면 선택 화면에 오류와 재시도를 표시하고 접속 잠금을 해제한다.
- 첫 맵 이미지 준비 후 악마화 나무의 정원에 진입하고 음성 1 독백 카드를 보여준다. 기존 저장 파일은 삭제하지 않는다.
- 요청한 그리스도 서문 → 合一 연출을 복원했다. 클릭/Enter로 넘기고 Esc로 즉시 종료할 수 있다. 구형 전투 맞대사와 인터루드는 복원하지 않았다.
- 설정을 전투 모드 / 소리 / 화면·터치 / 진행으로 정리했다. 구형 맞대사·인터루드, 개발용 피격 검사, 관리 코드, 중복 설명·편성 메뉴를 설정에서 제거했다.
- 터치 조작 선택은 실제 모바일 모듈의 자동/항상 표시/숨김 설정에 연결했다. 설정이 열린 동안 전투 터치 버튼이 화면을 덮지 않는다.
- 완전자동 독백 자동 진행 옵션을 실제 독백 타이머에도 적용한다.

## 검증

- 비브라우저 smoke 검사 26개 통과.
- 실제 Chromium: 8명 전원 신규 시작 → 첫 독백 → 전투 시간 진행, 이동/공격 입력. 페이지 오류 0개.
- 악몽검사: PC 및 터치 모바일(390×844)에서 시작·설정·3개 조작 모드·효과음·터치 표시 변경 통과.
- 맵 로더 의도적 누락: 선택 화면에서 준비 실패 표시, 접속 잠금 해제, 로더 복구 후 재시작 통과.
- 독백 112개: 1280×900, 390×844, 360×740, 844×390에서 글자·카드·버튼 화면 내 배치 통과.
- 전투 전후 독백 일시정지/한 번 표시, 최종전 전환, 사몽 흑백·시간정지 중 의목사 이동, 엔딩 저장 통과.

모든 맵을 처음부터 끝까지 수동 플레이한 결과는 아니다. 위 시나리오의 브라우저 검증과 자동 회귀 검사 범위에서 확인했다. PowerShell 스크립트 자체는 이 Linux 환경에서 실행하지 않았으며, 사용하는 패치 분리·적용 및 결과 Git 트리는 검증한다.
