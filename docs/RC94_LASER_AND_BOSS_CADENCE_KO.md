# RC94 — 레이저 이미지 복원과 보스 스킬 선택 수정

기준: GitHub RC93 `a373b4fd78a3703949e6ba975da1319688f3def1`, tree `bf6c7f4921d023ac79ea7d43298e294cbaef3394`.

## 확인한 문제와 변경

- RC91의 연결 레이저 렌더러는 곡선·복합 경로에서 준비된 보스 그림을 무시하고 단색 선을 그렸다. 이것이 이전 그림의 질감과 섬광이 사라진 원인이다.
- 일반 직선과 직선 분기는 이전 보스별 레이저 그림을 다시 사용한다. 곡선은 같은 그림의 몸통을 하나의 연속된 경로에 입혀, 구간마다 발사점 그림이 반복되지 않게 한다. 별도 저해상도 그림을 만들거나 기존 자산을 교체하지 않는다.
- 기존 RC91의 복합 경로 굵기 1.18배와 공통 피격 반폭을 유지한다. 두꺼운 곡선에서 접힌 띠가 생기지 않도록 연결부를 처리한다. 이미지 보간은 켜며, 저효과 설정에서도 그림을 표시한다.
- 정지 경로는 그린 결과를 재사용한다. 곡선은 가능한 환경에서 텍스처를 한 묶음으로 처리하고, 사용할 수 없으면 Canvas 2D로 처리한다. 텍스처 캐시는 8개로 제한한다.
- 레이저 설정에서 스킬 쿨타임 7.5/8.5/10초를 보스의 공통 `patternReadyAt`에 넣었다. 이 때문에 회복이 끝난 뒤에도 일반 스킬을 기다렸다. 레이저 쿨타임을 `laserReadyAtRC94`로 분리하고, 공통 타이머는 회복 종료 후의 짧은 간격을 따른다.
- 레이저 쿨타임·활성 레이저·진행 중인 강공 때문에 사용하지 못하는 레이저 카드는 선택 전에 제외한다. 직접 발동 경로도 같은 쿨타임을 검사한다. 이미 예약된 공격은 취소하지 않는다.
- 사몽에서는 분리한 레이저 재사용 간격에도 기존의 빠른 주기를 적용한다. 기존 적 HP, 공격력, 피격 피해, 각성 버프 값은 이 수정으로 바꾸지 않는다.
- 전장 대형 레이저 1개 제한, 궁극기 쿨타임, 탄환 수 제한, 공격 회복 시간, 독백·정지·페이즈 전환의 차단은 유지한다. 이번 수정은 이 제한을 무작정 해제하는 패치가 아니다.

## 검증

- JavaScript/CJS 215개 구문 검사, 비브라우저 회귀 검사 49종.
- 기존 브라우저 회귀 검사 17종: 영웅 동작, 이미지, 실전 첫 전투, 이동, 저장 복원, 각성, 코스믹 및 모바일 UI.
- 추가 RC94 네이티브 브라우저 검사: 활성 레이저 소유자 70종 × 스토리/사몽 × PC/모바일 = 280개 쿨타임·스킬 선택 사례. 원래 적 HP/최대 HP를 유지하면서 레이저 뒤에 일반 스킬이 실제 예약·생성되는 것을 확인한다. 쿨타임 중 레이저 재시도는 차단한다.
- 레이저 78종 × 대표 소유자 5개 × PC/모바일 = 780개 실제 픽셀 렌더링 사례. 디코딩한 보스 그림 사용, 색상 세부 정보, 캔버스 상태 복구를 확인한다. 정지 경로의 캐시 재사용도 검사한다.
- 등록 소유자 목록의 옛 `mb-ep1a07` 1종은 현행 활성 맵에 없으므로 활성 70종에서 제외한다. 원래 보스별 그림 및 연결 renderer의 기존 호출 지점은 유지한다.

브라우저 검사는 Linux Chromium의 PC·모바일 뷰포트에서 수행한다. 실제 휴대폰의 FPS나 모든 에피소드 자연 진행을 끝까지 보장하는 검사는 아니다.

## 적용

`APPLY_HAPIL_RC94_LASER_FIX.ps1`은 동일한 다운로드 폴더 안의 변경 없는 RC93 작업 폴더를 우선 사용한다. 없으면 새 폴더를 만든다. 기준/결과 tree와 패치 SHA256, 줄바꿈, 모든 구문 검사와 비브라우저 49종을 확인한 뒤 일반 push한다. Windows에서 브라우저 18종을 실행한 것처럼 표시하지 않는다. 다른 로컬 변경이나 원격 main 변경이 있으면 그 작업을 덮어쓰지 않는다.

Pages 배포 후 `?v=39401`로 접속하고 Ctrl+F5로 다시 로드한다.
