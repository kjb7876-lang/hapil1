# RC52 — 접속 준비와 그리스도 서문 복원

기준: RC51. 수동 적용용 단일 후속 패치.

- 시작 HTML에서 빠져 있던 기존 그리스도 서문, 배경, 合一 로고 전환과 연출 스크립트/CSS를 다시 연결합니다. 본문은 기존 서문 그대로입니다.
- 기존 접속 함수는 음성 초기화를 try/finally 바깥에서 실행했습니다. 초기화가 예외를 던지면 접속 중 플래그가 남아 후속 클릭도 무시될 수 있었습니다. 음성 실패를 접속 흐름에서 분리하고 모든 접속 실패에서 잠금을 해제합니다.
- 접속 준비 여부는 과거 버전 완료 표시 대신 실제 전투·보스·조작·맵 진행·맵 로딩·정본 서사 서비스로 확인합니다.
- 영웅 선택 화면에 준비 상태, 실패 안내, 다시 접속과 새로고침 버튼을 표시합니다. 준비 대기는 12초로 제한되며 연속 클릭으로 중복 시작하지 않습니다.
- 새 접속에서 남아 있는 이전 서사 참조를 정리한 뒤 기존 음성 1을 엽니다. 음성 1/2 원문·WAV, RC51 맵 서사와 사몽 전투는 보존합니다.

검증: 로컬 Chromium에서 실제 선택 버튼으로 8명 모두 음성 1에 진입. 그리스도 문구→로고→타이틀 확인. 준비 실패 표시와 재시도, 과거 완료 표시가 없는 경우, 음성 초기화 예외를 주입한 경우 확인. Node 회귀 19개 통과.

사용자가 보고한 브라우저의 오류 콘솔은 제공되지 않았으며, 공개 배포 주소는 이 실행 환경에서 직접 열리지 않았습니다. 위 검증은 저장소의 실제 배포 파일을 로컬 HTTP로 실행한 결과입니다.
