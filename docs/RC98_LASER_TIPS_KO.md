# RC98 레이저 끝처리

짧은 직선·격자 레이저를 원본 이미지의 사각형으로 그려 생기는 잘림을 수정했다. 보스 고유 이미지에 둥근 마스크와 끝·측면의 알파 감쇠를 적용한다. 새 공통 레이저 이미지나 충돌 없는 거대한 배경 효과를 덧씌우지 않는다.

마스크는 각 선분 안에서만 적용되어 RC97 회피 통로와 경고·접촉 판정은 바뀌지 않는다. 이미지별 비율 캐시는 최대 16개로 제한한다. 곡선의 기존 연결 렌더러는 유지한다.

검증: Linux Chromium 데스크톱/모바일 뷰포트의 RC97 네이티브 회귀 검사(각 69 보스, 12 질서 보스, 2278 경로 점), RC95 리듬·레이저·저장 검사, 52 비브라우저 검사. 같은 b08-boss 전투 상태의 렌더러 캡처로 위아래 레이저의 사각형 끝이 사라진 것을 확인했다. 실제 기기 전체 캠페인 검증은 아니다.
