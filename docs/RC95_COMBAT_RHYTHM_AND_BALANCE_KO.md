# RC95 전투 순환·발동·성장 밸런스 수정

기준: RC94 `aff10ab12c0ec1305ad57a688e80d923778ee930`. 배포 캐시: `39501`.

## 발견한 원인

- 레이저 예고가 선택형 예고 설정에 묶여 기본 설정에서도 숨겨질 수 있었다.
- 여러 보스 스케줄러가 동시에 패턴을 예약해 공격이 섞였다. 일부 호출자는 생성 결과의 `projectiles`/`lasers` 개수를 읽으므로 예약 보류도 같은 반환 구조를 유지해야 한다.
- A를 누를 때 대기 타격 배열을 24/48개로 잘라 이미 예약된 Q/W/E/R 타격이 유실될 수 있었다.
- 기본 공격 간격을 3.5배 단축한 보정이 A에서 자동 생성되는 Q/W/E/R 잔향 피해에는 적용되지 않았다. 직접 사용한 스킬과 자동 잔향을 구별해 같은 기본 공격 보정을 적용했다.
- 약점 노출 보상이 연속으로 갱신되고, 일반 전투의 공용 피해 예산이 별도 타격까지 0으로 만들 수 있었다. 시전 중 피해 감소 99%도 정상적인 스킬 적중을 무효처럼 보이게 했다.
- 기존 고정 체력은 플레이어의 스킬 성장·숙련·공격 스펙 차이를 충분히 반영하지 않았다.

## 최종 동작

레이저 보유 적이 있는 전투는 시뮬레이션 시간으로 **탄환 6초 → 레이저 6초 → 혼합 6초**를 반복한다. 일시정지와 시간 능력은 기존 시뮬레이션 시계에 따른다. 레이저를 쓰는 적이 없는 일반 몬스터 전투는 빈 레이저 구간을 기다리지 않는다.

새 공격의 예약을 순환 구간에 맞춰 조율한다. 이미 발사한 탄환이나 예약한 타격은 구간 경계에서도 끝까지 진행한다. 따라서 전환 직후에는 이전 공격의 잔여분이 잠깐 남을 수 있다. 보스는 원래의 레이저 카드와 탄환 이미지를 사용하고, 혼합 구간에는 원래의 특수 공격도 허용한다. 동시에 진행하는 레이저는 하나로 조율한다.

레이저는 저효과·섬광 완화·효과 투명도·선택형 예고 설정과 관계없이 먼저 경로를 예고한다. 새 보스 레이저는 2.1초, 중간 보스는 2.3초 예고 후 일반 패턴을 3.5초 유지한다. 거의 전장을 덮는 장막은 기존의 짧은 활성 시간을 유지한다. 이동 경로 예고는 최종 경로 하나로 줄였다. 원본 레이저 비트맵과 굵기는 유지하고 굽은 연결부에 질감이 있는 둥근 접합을 적용했다. WebGL과 소프트웨어 Canvas 경로 모두 검증했다.

탄환은 바닥 예고 없이 발사체를 보고 피한다. 새 순환 탄환은 예약 후 바로 보이고 이동·충돌한다. 탄환 구간은 0.72초, 혼합은 1.25초 간격으로 발사한다. 일반 탄환에는 강력한 보스 스킬의 최대 체력 비례 보너스를 적용하지 않는다. PC 56개/모바일 40개는 **새 탄환 생성 한도**이며 기존 발사체를 지우지 않는다.

이미 예약한 플레이어 스킬 타격을 보존한다. 일반 전투에서는 서로 다른 적중이 공용 피해 예산을 소모해 0이 되지 않게 했다. 시전 중 보스는 일반 전투에서 피해의 65%를 받고, 약점 노출은 보스 6초/중간 보스 4초 간격으로 갱신한다. 피해 숫자는 최종 적용 피해를 표시한다. 서사상 보호 대상·명령 개체·최종 전투 진행 게이트는 유지한다.

## 몬스터 체력 기준

전투에 들어온 적마다 한 번만 보정한다. 플레이어 A 및 자동 잔향, Q/W/E/R의 원래 피해·재사용 대기시간, 공격/스킬 성장, 숙련, 쿨감, 무한 성장, 인간/AI 편성, 진행 구간을 계산에 반영한다. 전투 중 스펙이 바뀌어도 기존 적의 체력을 다시 올리거나 회복시키지 않는다. 새로 들어오는 적은 그 시점의 스펙을 사용한다.

| 격 | 체력 산정에 사용하는 기준 시간 |
| --- | ---: |
| 일반 | 1초 |
| 정예 | 3.2초 |
| 중간 보스 | 22초 |
| 보스 | 46초 |
| 다단계·에피소드 보스 | 60초 |

위 값은 피해 모델의 체력 산정 계수이며 실제 처치 시간 보장은 아니다. 맵 진행에 따라 최대 25%, HELL/DREAM에는 별도 계수를 적용한다. 기존 체력이 적정 범위(산정 체력의 85~145%) 안에 있으면 유지한다. 성장 반영 지수는 0.78로, 성장할수록 적 체력은 늘지만 플레이어의 화력 이득도 남는다. 기존 사몽 배율은 따로 유지한다. 보호 대상·아군·중립 개체·소환물·최종 보호 보스는 이 일반 보정에서 제외한다.

보정된 최대 체력, 남은 체력과 순환 시간을 저장한다. STORY/HELL/DREAM 저장 후 입장 복원과 기존 능력치 보정 반복에서도 체력과 순환 구간이 유지됨을 확인했다.

## 검증

- 비브라우저 회귀 검사 50개, JavaScript/CJS 문법 검사 218개.
- Linux Chromium 브라우저 회귀 검사 19개. PC/모바일 보스 70종 × 3개 모드 = 검사 420건(순환 발동 414건, 보호 개체 제외 확인 6건).
- 캐릭터·성장 단계·모드·맵 몬스터 조합의 체력 보정 38,160건. 같은 전투에서 재보정·회복되지 않는지 확인했다.
- 기존 RC94 이미지·레이저 검사에서 780회 렌더링. 레이저 예고 강제 표시와 실제 소프트웨어 Canvas 접합 검사도 추가했다.
- 원래 전투 코드의 초반 적 처치 → 스토리 진행, 실제 Q/W/E/R 예약 보존, 같은 순간의 개별 피해 적용을 확인했다. 초반 진행 검사는 테스트 플레이어만 무적으로 만들며 적의 체력·피해와 전투 로직은 변경하지 않는다.
- Windows 업데이터는 50개 비브라우저 검사와 모든 JS 문법을 다시 검사한다. 브라우저 검사는 패키징 전 Linux에서 실행했다. 실제 Windows PowerShell 5.1 기기나 실제 모바일 전체 캠페인 벤치마크를 수행했다는 뜻은 아니다.

## 한 번 실행하는 업데이터

`APPLY_HAPIL_RC95_COMBAT_BALANCE.ps1`은 검증한 RC94 트리에 내장 패치를 적용하고 최종 트리를 확인한다. 기존 RC93/RC94 이름의 작업 폴더도 내용이 RC94이면 사용할 수 있다. 사용자가 수정한 폴더는 덮어쓰지 않고 새 폴더를 만든다.

LF 인덱스 파일의 Windows 줄바꿈과 캐시를 패치 적용 전에 정리하되 정본 CRLF 파일은 보존한다. 검사가 통과하고 원격 main이 그대로일 때 일반 push만 한다. 커밋 직후 업로드가 끊긴 경우 다음 실행에서 같은 검증된 커밋을 이어 올릴 수 있다. 이미 올라간 RC95는 재검증 후 중복 업로드하지 않는다.
