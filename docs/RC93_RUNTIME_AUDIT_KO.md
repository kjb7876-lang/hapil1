# RC93 이미지·전투 실행 경로 조사

2026-09-30. RC92의 수정사항을 유지하면서 실제 렌더러와 전투 프레임 검사를 확장했다. 조사 및 회귀 테스트는 최신 버전과 후반 맵부터 역순으로 수행했다. RC93은 추가 검증판이며 이번 추가 조사에서 새로운 게임 결함은 재현되지 않았다. 검사 장치의 초기 상태·비트맵 준비·상속 처리를 고친 것을 게임 버그 수정으로 집계하지 않는다.

## 누적 수정

RC90에서 적용하면 RC91과 RC92 개선을 함께 적용한다. 사몽 8영웅 위기 부활/각성, 연속 레이저, 회복 차단 중 부활 체력 유지, 저장 버전 검증 후 사몽 해금, 음수 프레임 시간 차단을 포함한다. 상세 원인과 수정은 `RC92_REVERSE_AUDIT_KO.md`에 기록했다. 실행 페이지의 캐시 키는 39301로 갱신했다.

동적 웨이브·온라인 협동에서 생성되는 모든 개체의 수를 267개 배치에 포함한 것은 아니다. 시그니처가 없는 보스의 모든 공격 변형을 2,088회 호출에 포함한 것도 아니다. 기존 레이저·보스·탄막·최종전 회귀 검사는 별도로 유지한다.

영웅 및 보스 검토용 이미지 모음은 게임의 실제 렌더러로 생성하여 직접 확인했다. 게임 원본 이미지를 새로 만들거나 교체하지 않았다. 큰 보스를 온전히 담도록 검사 캔버스 높이를 확장했으며 검사 화면의 잘림을 게임 결함으로 집계하지 않는다.

투사체 중 화면별 68개는 검사 시점에 정지 상태였다. 리듬의 안전 구간과 인과 홀드 등 의도적인 정지/충돌 금지 규칙이 포함된다. 이를 일률적으로 이동 실패나 이미지 누락으로 판단하지 않았다. 각 몸체의 네이티브 충돌 활성 여부를 기준으로 출력 여부를 검사했다.

## 전체 회귀 검사

- 비브라우저 49개와 Chromium 17개, 총 66개 테스트 통과.
- 자바스크립트/CJS 214개 문법 검사와 `git diff --check` 통과.
- 이미지 및 WAV 2,188개를 다시 디코딩하여 손상 0건 확인.
- 기존 역순 저장 검사: 활성 맵 61개(전투 55, 휴식 6) × STORY/DREAM × PC/모바일 = 244건. 적 HP/maxHP, 반복 능력치 스케일 비중첩, STORY 최종전과 사몽의 상태 분리 확인.
- 삭제된 `ep1a07`의 옛 저장이 `ep1a08`로 이동하는 별도 4건 확인.
- 시작/편성/설정/모바일 취소/입력 수명주기, 실제 첫 전투, 연속 레이저, 최종전/엔딩/저장 회귀 검사를 유지했다.

검사는 통제된 초기 상태와 공격/저장 fixture를 사용한다. 모든 영웅·난도·성장·파티 조합의 자연 캠페인 완주, 실제 휴대전화 성능, 온라인 동시 접속, 장시간 플레이, 사용자 Windows의 전체 브라우저 실행까지 검증한 것은 아니다. 모든 가능한 버그의 부재를 보장하지 않는다.

## 한 번에 적용

RC93 PowerShell은 검증된 RC90·RC91·RC92 내용 트리를 지원한다. 새 작업 폴더에 복제한 후 내장 패치 SHA256, 적용 결과 트리, 전체 자바스크립트 문법 및 비브라우저 테스트 49개를 확인하고 일반 push를 수행한다. 이미 RC93이면 재검증만 한다. 검사 중 main이 바뀌면 중단하고 작업 폴더를 보존한다.

포장 전에 Chromium 17개를 Linux에서 실행했다. 사용자의 Windows에서는 브라우저 테스트 17개를 생략한다고 표시한다. PowerShell 구문과 RC90·RC91·RC92에서의 적용/검증/커밋/일반 push/재실행은 별도 로컬 저장소로 검증했다. 이는 실제 GitHub 업로드나 GitHub Pages 배포 완료를 의미하지 않는다.
