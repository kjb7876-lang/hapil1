# RC97 선택을 빼앗는 압력과 되찾는 전투

중심 문장: **적은 내가 선택할 수 있는 공간을 빼앗고, 나는 회피와 공명으로 그 공간을 되찾는다.** 프로이트 이론의 임상적 재현이 아니라 HAPIL의 상징적 전투 설계다. J의 기존 서사는 수정하지 않았으며, 적의 통제 패턴과 자발적 합일을 동일시하지 않는다.

## 실제 변경

| 계열 | 탄환 문법 | 의미 |
|---|---|---|
| 집착·색욕 | 과거 발자국을 향하는 휘어진 탄류 | 현재 선택을 뒤쫓는 충동 |
| 탐욕·탐식 | 바깥에서 중심으로 모이는 탄류 | 공간을 자기 것으로 삼킴 |
| 분노·발록 | 박자에 맞춰 밀려오는 부채 파동 | 침범하는 압력 |
| 질투 | 좌우로 어긋나는 반영 탄류 | 비교와 왜곡 |
| 통제·막후·감독 | 반복되는 축 정렬 탄류, 복종의 격자 | 자신의 규칙을 강요하는 질서 |
| 기타 충동 | 회전하는 꽃잎·나선 탄류 | 확장하는 침범 |

보스 원본 레이저·탄환 이미지와 색을 사용한다. 이름만 바꾼 동일 탄막이 아니라 발사 위치·방향·곡률·박자가 다르다. 색을 제거해도 계열의 움직임이 구분된다. 72개 모두의 완전히 독립된 탄막을 새로 만든 것은 아니다.

- 탄환 6초 / 예고 레이저 6초 / 혼합 6초의 기존 순환을 유지한다. 다음 반복에는 회전 방향과 출구의 위험도가 변한다.
- 혼합 구간의 탄환은 직선 부채로 단순화하고, 진행 중 레이저의 주인이 주연 탄류를 담당한다. 모바일 40 / PC 56의 기존 발사 상한을 늘리지 않는다.
- 통제 계열 격자는 매 반복 간격이 줄어들고, 직전 반복의 최종 선택 구역을 압박한다. 충돌하는 격자는 한 발동 안에서 갑자기 이동하지 않는다. 예고와 발동이 같은 경로이며, 점진적 압축은 다음 예고에서 전달한다.
- 넓은 레이저 회피 경로와 좁은 그레이즈 경로를 구분한다. 두 경로는 예고·이미지·AI 위험도·실제 접촉이 공유하는 기하에서 열린다. 충돌체를 숨겨서 안전하게 보이게 하지 않는다.
- 일반 곡선은 원래 경로를 유지하면서 적정 폭의 레이저에 선택 경로를 적용한다. 특수 초광역 레이저에는 기존 기하와 대응 수단을 유지한다. 모든 공격을 동일한 격자로 대체하지 않는다.
- 통로는 **해당 레이저에 대한** 회피 경로이지 전체 탄환에 대한 무적 통로가 아니다. 이미 발사한 공격은 구간 전환에서 삭제하지 않는다. 혼합 구간에서는 탄환을 보고 움직여야 한다.
- 탄환은 별도 공격 예고 없이 즉시 보이며, 외곽에서 생성하는 탐욕 탄류는 플레이어 몸 위에 생성하지 않는다. 레이저의 필수 예고는 효과 설정으로 끌 수 없다.
- 기존 시간정지·시간둔화·그레이즈·패링 보상과 공명/EGO를 유지한다. 정지 시 탄환의 위치와 수명, 레이저 타임라인을 보존하고, RC97은 추가로 6초 순환 시계도 정지 시간만큼 늦춘다. 새 탄막으로 교체하거나 기존 탄막을 지우지 않는다.
- RC96 공명 HUD와 차징 중 자동공격·자동스킬은 포함한다. 저장된 상처나 플레이어 성장 밸런스를 재설정하지 않는다. 영웅/맵 변경·시간 역행 시 선택 관찰 기록은 새로 시작하며, 과거 경로 기록 자체는 영구 저장하지 않는다.

## 검증 범위

새 단위 검사: 6계열 움직임, 혼합 단순화, 넓은/좁은 실제 접촉 경로, 네트워크 입력 범위 검증, 선택 기록, 정지 시 순환 시계.

새 네이티브 브라우저 검사: 공격 가능한 레이저 주인 69종의 실제 탄환 이동·이미지 디코딩·레이저 유효성, 통제 격자의 동일 예고/발동, 선택 경로 접촉과 이동 가능 영역, 시간정지 후 같은 탄환의 재개. PC/모바일 뷰포트에서 수행한다.

회귀: RC95 전투 순환·성장/저장·연결된 이미지 레이저, RC96 차징/HUD, RC93 영웅 행동, RC69 상호작용. Windows 업데이터는 비브라우저 52개와 모든 JS/CJS 문법을 다시 검사한다. Linux Chromium 검사이며 실제 모바일 기기 전체 캠페인, 무조건적인 무피격 경로 또는 모든 버그 부재를 보증하지 않는다.

배포 캐시: `39701`. RC94/95/96 기준 모두에서 RC97 하나로 누적 적용한다. 기존 사용자 변경은 덮어쓰지 않고, main 변경을 확인한 뒤 일반 push만 사용한다.
