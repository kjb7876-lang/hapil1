# RC96 공명 표시·차징 중 자동공격

기준: 검증된 RC95 트리 `e7e03e7e15b80900831e6dd2dc45123634b5c2bd`. 배포 캐시 `39601`.

- 공명을 별도 숫자와 막대로 표시한다. PC는 우측 상단, 모바일은 설정 버튼 옆 상단에 배치하고 터치 입력을 가로채지 않는다. 기존 최소 UI·S/D 두 버튼은 유지한다.
- `공명 73 / 100`, 100의 각성 준비, EGO 각성 남은 시간, 차징 진행과 강화 사격 대기를 구분한다. 효과 설정으로 숨겨지지 않으며 전투 수치를 HUD가 바꾸지 않는다. 100ms 간격으로 기존 상태를 읽는다.
- 기본 전투 모드인 반자동은 기존처럼 기본 공격과 공격 스킬을 자동 사용한다. 차징을 이유로 기본 공격·자동 스킬·네이티브 스킬을 막던 조건을 제거했다. 회복형 스킬의 기존 연계 규칙과 실제 행동 제한은 유지한다.
- 차징을 유지하는 동안 나가는 기본 공격은 정상 피해다. 기존 EGO 차징 입력과 0.6/1.2초 단계는 유지한다. 충전 해방 시 정상 공격 간격을 우회하지 않고 다음 유효한 기본 공격에 강화 효과를 한 번 적용한다. 자동 공격 직후 놓아도 강화 사격이 사라지지 않는다.
- 수동 모드에서도 이미 해방한 충전은 공격 간격이 끝나면 한 번 발사하지만, 이후에는 자동 공격하지 않는다. 타격 큐를 삭제하거나 일반 공격 속도를 높이지 않는다.
- D 방어, 피격, 사망, 일시정지, 영웅/맵/입력 컨텍스트 교체 시 기존 차징 취소 규칙을 유지한다. 미발사 충전은 이런 경계를 넘어 새 전투로 옮겨가지 않는다.

검증: 비브라우저 검사 51개와 모든 JS/CJS 문법. 실제 네이티브 코드로 8영웅 × PC/모바일에서 차징 중 기본 공격 15회와 자동 스킬 발동, 충전 보존·한 번만 적용·수동 모드·일시정지 취소를 검사했다. 별도 회귀 브라우저 검사는 RC95 순환·밸런스, RC93 영웅 행동, RC69 상호작용이다. 실기 전체 캠페인 벤치마크는 아니다.

RC96 PowerShell 업데이터는 RC94에서 시작하면 RC95를 포함한 누적 패치를 적용하고, RC95에서 시작하면 해당 기준의 차이만 적용한다. 변경된 사용자 파일을 덮어쓰지 않으며 일반 push만 사용한다. 적용 후 51개 비브라우저 검사와 모든 문법을 다시 확인한다.
