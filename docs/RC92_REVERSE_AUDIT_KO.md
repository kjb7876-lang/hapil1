# RC92 역순 조사 및 회귀 검증

2026-09-30. 검증 기준: RC90 원본 + RC91 검증 패치. 조사 방향은 최종전/엔딩 → 후반/중반 맵 → 첫 전투 → 시작/편성/설정이다. 자동 검사는 최신 릴리스부터 역순으로 실행했다. 이는 모든 가능한 플레이 조합의 무결함 보장이 아니다.

## 재현 후 수정

1. **회복 차단 중 사몽 위기 부활 취소**: 치명타 직전의 `heroHealingCeiling`이 남아 다음 네이티브 상태 처리에서 부활 체력이 다시 낮아졌다. 부활 시 상한만 복원 체력으로 이동한다. 회복 차단 시간과 일반 회복 제한은 유지한다. 8명 모두 네이티브 피격/상태 처리로 재검증했다.
2. **지원하지 않는 저장 버전의 사몽 해금**: 저장 버전 검증보다 `unlocked` 적용이 먼저 실행됐다. 두 복원 경로에서 `sanitize()`를 통과한 저장만 해금에 사용한다. 유효한 v1 저장은 계속 복원한다. 이는 저장 데이터 형식 검증이며 서버 인증/변조 방지 기능은 아니다.
3. **프레임 시간 방어**: visibility 이벤트와 이미 예약된 프레임의 순서가 뒤집혀도 음수 delta가 시뮬레이션에 전달되지 않도록 0으로 제한한다. 기존 숨김 탭 시계 초기화는 유지했다. 숨김 시간이 기존에 항상 누적되었다고 주장하지 않는다.

## 검사 범위

- 비브라우저 테스트 49개: 문법/런타임 게이트, 저장 순서, 전투 판정, 스킬/레이저, 보스, 서사, 영웅 이미지, 시작, 모바일 정책, 사몽 스케일/쿨다운 회귀.
- Chromium 브라우저 테스트 15개: 실제 UI 시작, 편성 8명, PC/모바일, 입력/터치 취소, 설정, 첫 전투, 네이티브 레이저, 최종전, 엔딩 및 저장 수명주기.
- 활성 맵 61개(전투 55, 휴식 6)를 역순으로 STORY/DREAM × PC/모바일로 검사: 저장/복원 244건. 각 모드에서 적 HP/maxHP, 반복 스케일 비중첩, 사몽에 STORY 최종전 상태가 섞이지 않는지 확인했다.
- 삭제된 `ep1a07`은 활성 전투가 아니다. 옛 저장이 `ep1a08`로 이동하는 기존 규칙을 별도 4건 확인했다. 이를 새 버그나 활성 맵 복원 실패로 집계하지 않았다.
- 역순 맵/8영웅 자산 매니페스트 경로 1,407개는 각 화면 조건에서 파일 존재를 확인했다. 정적 자산 참조 검사도 별도로 수행했다.
- PNG/WebP/JPEG/GIF 및 WAV 2,188개를 실제 디코딩하여 손상 여부를 확인했다(0건). 시각적 품질/모든 애니메이션 연출의 적합성까지 보장하는 수치는 아니다.
- 자바스크립트/CJS 전체 문법 검사와 `git diff --check` 수행. 페이지 캐시 키는 39201.

## 테스트 장치 변경과 실제 수정의 구분

`rc85-combat-browser.cjs`는 실제 사거리/시야가 유효한 위치에서 정상 레이저 요청을 재시도하도록 안정화했다. 적 체력/피해를 낮추거나 전투 큐를 삭제하지 않는다.

`rc51-browser.cjs`의 엔딩 fixture는 이제 최종전 시간/소환 처치/최종타 조건이 완료된 상태를 명시한다. 단순히 적 배열을 비우면 엔딩이 거부되는 것은 현재의 정상 보호 규칙이다. 이 테스트는 자연 플레이로 최종전을 완주했다는 증거가 아니다.

`mobile-smoke.cjs`는 제공된 Chromium 실행 파일과 Playwright 경로를 사용하도록 이식성을 보완했다. 실물 휴대전화 벤치마크는 아니다.

## 적용 및 한계

RC92 PowerShell 파일은 RC90 또는 검증된 RC91 내용 트리에서 시작한다. RC90에는 RC91 개선도 누적 적용한다. 새 폴더에 복제하며 기존 작업 폴더는 변경하지 않는다. 내장 패치 SHA256/결과 트리/49개 비브라우저 테스트를 통과한 뒤 일반 push만 수행한다. main이 달라지면 중단하고 작업 폴더를 보존한다. 이미 RC92인 경우 재검증만 한다.

브라우저 15개는 포장 전에 Linux Chromium에서 실행했다. 사용자 Windows에서는 문법/49개 테스트가 실행되며 Playwright 테스트는 생략한다. 실제 Windows 전체 실행, 온라인 협동 동시 접속, 실물 기기 장시간 플레이, 모든 경로의 자연 캠페인 완주는 별도 검증이 필요하다. GitHub Pages 배포 완료도 업로드 성공과 구분한다.
