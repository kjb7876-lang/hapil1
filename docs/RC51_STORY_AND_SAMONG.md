# RC51 — 업로드 정본 서사와 스토리 최종전 사몽 각성

기준 커밋: `d56d5c1` (RC50). RC45~RC50을 다시 포함하지 않는 단일 변경 패치입니다.

## 서사

- 업로드한 원본을 `data/rc57/voice-monologue.txt`에 바이트 그대로 보존했습니다.
- 기존 음성 1/2 텍스트·WAV·자동 음성 재생 경로를 보존합니다.
- 나머지 기존 인터루드, 맵 진입 맞대사, 단서의 서사 팝업, 구버전 최종전 대사창은 활성 표시 경로에서 제외합니다. 예전 데이터 파일은 초기화 호환 검사 때문에 남아 있으며 새 서사 표시에 사용하지 않습니다.
- 56개 기존 전투맵에 전투 전/후 서사 한 번씩 표시합니다. 6개 쉼터 원고는 앞 전투 후/다음 전투 전 화면에 순서대로 포함합니다.
- 삭제된 8번 기록에 새 문장을 만들지 않았습니다. 기존 `ep1a07` 맵에는 앞선 ‘추락’ 원고의 후반 두 문단을 이어 배치했습니다.
- 맵을 추가할 필요가 없어 지형·카메라·기존 자산을 유지했습니다.
- 최종전은 1차 전투 후 회상 → 사몽 각성 전 서사 → 2차 전투 → 결말 순서입니다. 일반 전투 112장 + 최종전 중간 2장 = 새 서사 화면 114장입니다.
- 서사와 독백 어조는 업로드본을 따르고, 사용자가 앞서 요청한 맞춤법·띄어쓰기만 보정합니다. PC/모바일 한 화면 표시, 가로 모바일 2단, 휠/페이지 넘김 없음. 작은 화면에서는 글자가 작아집니다.
- 수동/반자동은 ‘계속’ 또는 Enter/Space로 진행합니다. 완전자동은 글 길이에 따른 대기 후 진행하며 자동 넘김을 멈출 수 있습니다. 읽는 동안 전투·키 입력은 정지합니다.
- 미카엘라의 기록일지도 같은 정본으로 교체합니다.

## 스토리 최종전 사몽 각성

발동 조건: STORY + `cult04` + 최종전 2차 단계의 전투 재개 + 살아 있는 환도. 각성 장면에서 환도로 전환합니다. HELL, DREAM, 연습모드에는 이 추가 효과를 적용하지 않습니다.

- 전체 화면 흑백. 기존 이미지 재사용.
- 적이 사용하는 공통 전투 시계: 평상시 16% 속도, 2.8초 주기 중 1.2초 완전 정지. 적 AI, 레이저, 스킬 시간, 탄환 이동이 함께 영향을 받습니다.
- 의목사 이동 1.7배, 공격/재사용 시계 2.2배, 기본 공격 범위 1.4배.
- 캐릭터 표시 크기 1.3배, 영웅 효과 크기 1.55배, 이동 잔상.
- 추가 피해 배율 5배, 받는 피해 배율 0.12. 최종전 2차 각성 중에만 이전 공격 연출 종료를 기다리는 보스 체력 잠금을 해제합니다.
- 엔딩/다른 맵/다른 모드/사망 시 추가 효과 해제.

## 확인

- Node 회귀 검사 19개 통과.
- 업로드본 SHA-256 및 원문에서 보정한 텍스트를 각 전투 전·후 카드와 대조하는 검사 통과.
- 브라우저에서 114장 × 4개 화면 크기(1280×900, 390×844, 360×740, 844×390): 본문 및 버튼 잘림 없음.
- 브라우저에서 진입 → 전투 → 승리 서사 1회, 읽는 동안 게임 시간 정지 확인.
- 최종전 1차 종료 → 회상 → 각성 → 흑백 화면 → 정지된 세계에서 영웅 이동/공격과 보스 체력 감소 확인.
- 최종 원고 확인 후 기존 엔딩/자동 저장 경로 실행 확인.
- 전체 56개 맵을 수동으로 끝까지 플레이한 검증은 아닙니다. 맵 매핑·원문·레이아웃은 전수 검사하고 전투 흐름은 대표/최종전 경로로 확인했습니다.
