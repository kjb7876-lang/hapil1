# RC88 — 공격으로 격파하는 서사 탄막 성장 RPG

RC85 기준 누적 패치. RC86 목사 이미지 통일·사몽 코스믹 호출과 RC87 에피소드별 코스믹 진최종 보스도 포함한다. 원본 독백과 에피소드 진행 순서는 유지한다.

| 전투 | 적용한 규칙 |

| 일곱 대죄 | 기존 보스 고유 투사체 그림을 유지하고 탄 수·속도·연속 발사 박자를 구분한다. |

부속은 일반 적의 체력·피격 경로를 이용한다. 본체와 부속 모두 공격으로 처치할 수 있다. 부속은 보스의 강제 페이즈 전환·99% 시전 방어·초당 보스 피해 예산을 상속하지 않는다. 부속 격파의 약점 노출 동안 본체 피해량은 1.4배, 초당 피해 예산은 1.25배가 되며, 시전 방어가 피해를 지나치게 차단하지 않도록 최소 35%를 통과시킨다. 기존 본체의 페이즈·엔딩 게이트는 그대로 적용한다.

## 격파·성장 보상

- 부속·사몽 소환체 격파: 공명 +6, 4초 동안 사용할 강화탄 최대 3회.
- 실제 패링 성공: 같은 강화탄 1회. 별도의 조작이나 새 성장 화면은 없다.
- 강화탄은 다음 영웅 공격 적중 때 발동한다. 뒤에 나란히 선 적이 있으면 관통, 다른 적/부속이 있으면 분기, 단일 대상이면 집중탄을 발사한다.
- 기존 영웅의 이미지, 성장에 따른 기본 공격 피해, 투사체 도착 시점, 피격 판정을 재사용한다. 강화탄이 다시 강화탄을 발생시키는 재귀는 차단한다.
- 환도의 지원 검격은 기존 투사체를 양쪽에서 보내는 단순한 연출이다. 새 동료 캐릭터나 새로운 애니메이션 시트를 추가하지 않는다.

## 시간·정리·저장

각성 최종전의 세계 시간은 느려지므로 사몽 호출 간격과 소환체 체류 시간에는 RC79의 실제 전투 시간 `combatElapsedRC79`를 사용한다. 투사체 이동과 피격은 기존 세계 시간을 사용한다. 60초 엔딩 제한을 해제하지 않는다. 소환체는 최종 보스 체력의 1.8%를 기준으로 만든 처치 대상이며, 최대 5.5초의 호출 구간 후 퇴장한다. 시간 만료에는 격파 보상을 주지 않는다. 처치하면 다음 호출을 0.85초 후로 당긴다.

발사원의 죽음이나 소환 종료는 이미 확정한 탄막·레이저·지연 공격을 삭제하지 않는다. 이 공격은 기존 수명과 충돌 규칙으로 끝난다. 최종전 종료·맵 종료에서는 기존 정리를 사용한다. 파괴된 핵, 살아 있는 부속의 체력, 다음 발사까지 남은 시간, 사몽 호출 순서·현재 소환체 체력·격파 누적을 저장한다. 맵 이동 시 이전 맵의 부속 상태를 가져오지 않는다.

추가 탄막은 기존 PC/모바일 투사체 예산 안에서만 생성한다. STORY·HELL에 적용하며 DREAM·BOSS·연습 전투에 새 부속 규칙을 추가하지 않는다. 기존 보스의 패턴에 작은 파동을 보강하는 방식이다.

## 검증

- 비브라우저 테스트 45개. RC88 전투·사망·공격 유지·성장·복원·모드 경계·엔딩 바닥 체력 검증 포함.
- RC88 Chromium: 18개 정적 전투 경로, 기존 전투 이미지 17개, 코스믹 6종 대표 패턴, 부속 실제 피해 함수, 기본 저장/복원, 호출 도중 복원. 파란불은 동적 보스이므로 VM의 별도 경로 검증을 사용한다.
- RC85 Chromium: 첫 전투의 자연 공격·사망·독백 진행, 실제 전투 페이즈 레이저 이미지, 악몽검사 28개 자세. 첫 전투에서는 테스트 플레이어 체력만 유지하며 적 체력·공격 피해는 변경하지 않는다.
- RC86/RC87 Chromium: 목사 이미지 경로, 코스믹 고유 패턴, 에피소드 진최종 보스 6회, 엔딩 경계, 저장된 본체 체력·패턴 지연 복원.

이 검증은 모든 에피소드를 사람처럼 끝까지 플레이한 난이도 평가를 대신하지 않는다. 새 발사 파동의 속도와 부속 체력 비율은 이후 실제 플레이 피드백으로 조절할 수 있다.
