# RC86 사몽 최종전·이단의 목사 감사

## 조사 결과

- `kair-great-01`부터 `kair-great-06`까지 실제 보스 액터, 이미지, 3개씩의 고유 시그니처 탄막 덱은 이미 등록돼 있었다.
- 하지만 여섯 액터의 일반 `final-kairo` 기술 목록은 같은 네 패턴을 공유했다. 고유 탄막은 일반 전투 루프가 각 보스의 원래 맵에서 선택할 때만 발사됐다.
- 보스 종결 광로는 출처 보스의 원래 구역을 요구하므로 `cult04` 사몽 경기장에서 직접 부르면 차단됐다. 사몽 2페이즈의 호출 경로도 없었다. 결과적으로 여섯 이름과 이미지가 있어도 사몽이 여섯 보스를 불러 고유 공격을 하는 흐름은 연결되어 있지 않았다.
- 기존 DREAM의 여섯 지역 보스는 코스믹 대수문장 여섯 보스가 아니다. 표기만 잘못 연결돼 있어 `사몽 시련 1–6`으로 구분하고 원래 순서와 지역 전투를 보존했다.
- 한리안·백이온의 RC55 공격 경로는 일부 포즈에서 정규 영웅 이미지를 다시 사용해 복장과 실루엣이 바뀌었다. RC86은 대기·시전·공격 슬롯을 각각 일관된 이단의 목사 이미지에 고정한다.

## 변경

- `cult04`의 `c104-boss`, 전투 2페이즈, 단색 연출 시작 이후에만 사몽 호출 파동을 시작한다. Story와 Hell에서 동작하고 DREAM에는 개입하지 않는다.
- 실제 Kair 대수문장 원본 액터를 한 명씩, 여섯 순서로 등장시킨다. 각 소환은 원본의 고유 시그니처 덱과 위상별 안무 생성기, 탄환·레이저 발사기를 호출한다. 소환은 적대 대상으로 강제되며 자체 체력 소진으로 최종 맵을 끝내지 않는다.
- 각 시그니처 발사는 실제 전투 큐를 생성한다. 소환 퇴장 때 그 소환의 탄환·타격·레이저 출처를 정리하며, 최종 보스의 전투와 맵 클리어 권한은 그대로 둔다.
- DREAM 지역 보스 시련은 기존 여섯 지역·순서를 보존한다. 이름을 `코스믹 1–6`에서 `사몽 시련 1–6`으로 고쳐 혼동을 제거한다.
- 한리안과 백이온은 새 대기·행동 PNG를 사용하고, `phaseSprite`와 모든 액션 슬롯에서 같은 정체성과 장비를 유지한다. 이미지 캐시/맵 자산 계획도 새 파일에 맞춘다.

## 검증

- 정적/VM 스모크: 고유 보스 여섯, 서로 다른 시그니처 덱, DREAM 격리, Story/Hell 허용, 1페이즈 차단, 소환 정리, 두 목사의 대기·공격 이미지와 PNG 알파 확인.
- 브라우저 통합: 실제 브라우저 번들에서 6개 원본 덱을 호출해 실제 적 탄환·레이저 큐 생성 확인. 순차 소환 종료 뒤 잔여 적 투사체가 없고 `c104-boss`가 클리어 권한을 유지하며 브라우저 예외가 없는지 확인.
- 기존 스토리/사도 연결 테스트와 전체 비브라우저 회귀 테스트는 업로드 스크립트에서 실행한다.
