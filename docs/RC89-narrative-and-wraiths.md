# RC89 · 서사와 탄막 전투 정합성

RC86–88 누적 변경을 포함한다. GitHub RC85 커밋 e1bb67a90a7fa052424c3175df3daa536c69b2fe를 기준으로 적용하며 아직 게시하지 않았다.

- 에피소드 중요 보스 뒤 코스믹 진최종전은 유지한다. 최후 cult04에서 교주의 사몽으로 재등장하는 여섯 코스믹은 망령이며, 독백에 꼭두각시라는 의미를 보충했다. 반투명 흑백 원본 자세와 교주 연결선을 사용한다. 망령 격파는 교주 방벽을 약화하며 최종 처치 조건은 기존대로 보존한다.
- kair02 아르벨리아는 몸을 공격하지 않는다. 변조된 명령 핵 세 개를 탄막으로 파괴한 뒤 몸의 사망 이미지를 남기지 않고 해방한다. 기존 보상·진행 콜백을 재사용하며 해방 완료를 저장한다.
- ep1b09 부트로더의 검을 내려놓고 연산핵에 연결하는 원문 문단은 전투 후로 옮겼다. 복제체는 동료 자산을 우선 사용한다. 본체 격파 후 1.2초 연결 연출을 거쳐 기존 코스믹 후속전 콜백을 호출한다. 연결 잔여 시간도 저장한다.
- 환도의 두 주인은 라우렌 창 자산과 기존 공격 판정으로 좌우 지원한다.
- murder03 후반 카드에 〈한이경의 기억〉을 표시한다. 원본 업로드 파일과 그 해시는 유지하며 런타임 카드·문단 내보내기·전체 감사표를 일치시킨다.
- 사몽 망령의 HP, 호출 순서, 격파한 방벽, 남은 체류 시간을 복원한다. 부속 격파 전 이미 발사된 탄막은 고유 수명까지 유지한다.
- 강화탄의 반복 중앙 문구를 제거했다. 사몽 호출은 기존 짧은 안내를 유지하며 방벽 상태는 보스 위 표시로 전달한다.

검증: 비브라우저 테스트 46개와 추적 JavaScript 구문 검사, RC85 첫 전투 실제 처치 및 악몽검사 28개 자세, RC86 여섯 소환의 고유 패턴과 목사 이미지, RC87 에피소드 후속전, RC88 전투 부속·망령 이미지·잔여 체류 시간 복원 브라우저 검사. QA 생존 보조와 일부 인공 상태를 사용하므로 전 에피소드의 자연 플레이 난이도를 검증했다는 뜻은 아니다. Windows 업로더는 비브라우저 테스트를 다시 실행하며 브라우저 테스트는 건너뛴다.
