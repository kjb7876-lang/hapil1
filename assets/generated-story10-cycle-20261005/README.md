# Generated story 10 and circular-murder art: asset-only staging

This directory contains the exact 14 final PNGs shared by HAPIL main and the separate StoryWorld consumer. It is a transfer handoff, not a runtime integration or deployment. No existing repository files are changed.

- `ep1a10/`: hospital-denial map, white-mask pursuer atlas, and pride-ruin-core atlas.
- `cyclic-murder/`: three blue-executor boss poses and idle/lurch poses for Yoon Haram, Jang Minjae, Go Seojin, and Han Igyeong.
- `ep1a10-manifest.json`: original manifest with only final generated-asset file paths adjusted to this repository location. Unequal source rectangles, pivots, identity data, and alpha checks are preserved.
- `cyclic-murder-manifest.json`: original manifest with only the final PNG file/localFile paths adjusted to this repository location. Anchor, alpha-bound, and visual hurtbox guides are unchanged.
- `metadata/original-*-manifest.json`: byte-identical source manifests for provenance. Historical local paths, previews, prompts, and source references in these manifests are not part of this staging handoff. Historical art-task scope flags do not describe the later staging commit.
- `file-sha256-manifest.json`: bytes, SHA-256, and Git blob SHA-1 for every other staged file.

PNG bytes are unchanged from the approved generated deliverables. No editing, scaling, recompression, cropping, or regeneration occurred during staging. Retain the original alpha. The ep1a10 actor atlases use explicit unequal sourceRects; do not split them into equal thirds. Circular-murder PNGs are standalone poses, not atlases, at 1254 by 1254 RGBA. Preserve the supplied ground anchors across pose changes. Collision guides require consumer-engine validation.

The HAPIL main integration owner remains responsible for copying/using these files on its working branch, testing the combined game, and any main/Pages publication. StoryWorld may fetch/copy the same immutable assets into its existing separate project; this branch does not publish StoryWorld. Fetch this branch or commit, then copy only this directory. Do not merge the branch as a substitute for reviewing integration.
